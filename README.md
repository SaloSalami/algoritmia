# Algoritmia

En este trayecto se practica cómo resolver problemas paso a paso con algoritmos. Se usan variables, operaciones, decisiones, ciclos y funciones, principalmente en PSeInt.

## Entregas

- **smn1:** ejercicios básicos de entrada y salida, cálculos, diagramas de flujo y las instrucciones para preparar un tinto.
- **smn2:** ejercicios de lógica y decisiones: registro, propinas, parqueadero, inventario y año bisiesto. Incluye una práctica complementaria en JavaScript.
- **smn3:** ejercicios con ciclos y subprocesos: cajero, notas, usuario, pirámide y factura. Incluye un ejercicio de compra en JavaScript.

Cada carpeta contiene sus programas y un `resumen.md` con explicaciones y ejemplos.
